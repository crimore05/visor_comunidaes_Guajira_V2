# Visor de Shapes · La Guajira

Visor web (Leaflet) de 25 capas convertidas desde shapefile a GeoJSON.
Abrir con un servidor: `python -m http.server` y luego http://localhost:8000
(con doble clic en index.html el navegador bloquea la carga de datos).

Publicado con GitHub Pages: Settings → Pages → Branch `main` / root.
